# **STORAGE BUCKETS**

Supabase Storage holds media bytes. The API reaches every bucket only through `SupabasePort`
([app/ports/supabase/spb.py](../../app/ports/supabase/spb.py)). Object keys for originals live on `public.medias`
(`storage_path`, `thumbnail_path`). The table is in [erd.dbml](erd.dbml).

This API writes only `resized`. It only reads `medias` and `thumbnails`. `POST /medias/videos` is still a stub, so
uploading an original is not an API route.

## `medias`

Original images and videos.

The object key is the row's `storage_path`. When the media is an image, thumbnail generation downloads those bytes
with `storage_media().download`.

## `thumbnails`

The still image for a video. Pillow cannot decode video, so this still is the source image for a resized thumbnail.

The object key is the row's `thumbnail_path`. The API reads it only when `Media.is_video`, with
`storage_thumbnails().download`.

## `resized`

JPEG thumbnails generated by this API.

The object key is `{media_id}/{width}x{height}.jpeg`, built by `CreateMediaThumbnailService.__make_thumbnail_path`.
The API uploads the file here and returns a signed URL that lasts 1800 seconds.
